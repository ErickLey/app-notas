# Guía de Contribución

Gracias por colaborar en este proyecto. Sigue estos pasos para reportar problemas o proponer cambios:

## 🐛 Cómo reportar un error
1. Revisa la pestaña **Issues** para confirmar que no fue reportado previamente.
2. Crea un nuevo Issue especificando qué esperabas, qué ocurrió realmente, la ubicación del archivo y cómo reproducir el error.

## 🚀 Cómo proponer una mejora
1. Haz un *Fork* del repositorio.
2. Crea una rama descriptiva para tus cambios (`git checkout -b fix-nombre-mejora`).
3. Confirma tus cambios mediante commits claros.
4. Envía un *Pull Request* referenciando el Issue correspondiente.

## ✅ Checklist para Pull Requests
- [ ] Los cambios han sido probados en el navegador.
- [ ] No se modificaron archivos no relacionados con el error.
- [ ] El título del Pull Request describe claramente el aporte.
